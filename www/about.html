Architectural Overview

Localhost is an event-driven HTTP/1.1 server implemented in Rust without third-party web frameworks, following strict Unix and RFC standards.

Core Design Principles

  • Single Thread & Single Process: The main event loop runs on a single thread utilizing non-blocking system I/O (epoll on Linux, WSAPoll on Windows).
  • No Crash Guarantee: Robust error propagation via Rust's Result type with zero unhandled unwraps on network sockets.
  • Request Timeout Management: Inactive or slow clients are timed out gracefully (HTTP 408) to preserve server resources.
  • Multi-Port Multiplexing: Listens simultaneously across multiple TCP ports and maps requests using virtual hosting rules.
  • Chunked Transfer Decoding: Full RFC 7230 §4.1 compliant parser handling unchunked and chunked payloads.
  • Common Gateway Interface (CGI): Spawns child processes passing standard environment variables and piping request bodies via stdin EOF.

Supported HTTP Methods

The server supports GET, POST, and DELETE methods. Non-allowed methods on specific routes automatically trigger a 405 Method Not Allowed response containing the RFC-compliant Allow header.
